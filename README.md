# Платежный контроль · 19–25.10.2026

Готовый статический дашборд для GitHub Pages.

## Что внутри
- KPI: все платежи / собственные / кредит / доля кредита
- фильтры по источнику, направлению и юрлицу
- поиск по назначению платежа
- графики по направлениям и юрлицам
- структура собственного и кредитного финансирования
- таблица всех платежей
- автоматический деплой через GitHub Actions

## Публикация
1. Создай новый репозиторий на GitHub, например `payment-dashboard`.
2. Загрузи содержимое этой папки в корень репозитория.
3. В репозитории открой **Settings → Pages**.
4. В разделе Build and deployment выбери **GitHub Actions**.
5. После push workflow опубликует сайт.
6. Ссылка будет вида:
   `https://USERNAME.github.io/payment-dashboard/`

## Важно
Файл `data.js` содержит финансовые данные платежного календаря. Не публикуй репозиторий/сайт в открытый доступ, если эти данные являются конфиденциальными и у тебя нет разрешения на публичное размещение.


## Согласование платежей

В реестре у каждого платежа есть кнопки **«✓ Согласован»** и **«✕ Не согласован»**.
Статус сохраняется в браузере через `localStorage`, поэтому после перезагрузки страницы на этом же компьютере он не пропадает.

Важно: это локальное сохранение. Если несколько сотрудников должны видеть и менять один общий статус, нужен общий backend/таблица (например, Google Sheets, Supabase или корпоративная БД). В текущей статической версии изменения одного пользователя другим пользователям не видны.
